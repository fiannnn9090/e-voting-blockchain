# Contributing

Thank you for contributing to this research implementation. Please follow these simple guidelines.

1. Fork the repository and clone your fork locally.
2. Create a descriptive branch: `git checkout -b feat/short-description` or `fix/short-description`.
3. Follow existing coding style: CommonJS modules, minimal inline comments, and consistent indentation (2 spaces).
4. Commit messages: use imperative mood and include a short scope when appropriate, e.g. `validation: add non-destructive clone` or `blockchain: fix merkle duplication`.
5. Pull request:
   - Target branch: `main`.
   - Include a clear description of the change, motivation, and any experimental impact.
   - Reference any related issue numbers.
   - Ensure tests pass (`npm test`) and update documentation if behavior or APIs change.

We appreciate concise, well-documented contributions. For questions, open an issue before making large changes.
