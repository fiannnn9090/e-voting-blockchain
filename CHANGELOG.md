# Changelog

All notable changes to this project will be documented in this file.

The format is based on "Keep a Changelog" and this project adheres to [Semantic Versioning](https://semver.org/).


## [1.0.0] - 2026-08-05

### Added

- Initial release
- Blockchain-based e-voting implementation
- RSA Digital Signature support for vote signing and verification
- Merkle Tree implementation for transaction aggregation and root verification
- Audit Ledger to record audit entries alongside the vote ledger
- Blockchain Explorer (ledger inspection utilities)
- Admin Dashboard (administration and election settings)
- Automated Testing (Jest + Supertest-based API tests and mocks)
- Benchmark Framework (RSA, Merkle, Block creation and chain verification benchmarks)
- Integrity Validation Framework (research harness for Original Blockchain and Tampered Vote scenarios)
- Documentation (README, BENCHMARK.md, VALIDATION.md, TESTING.md and other supporting documents)
